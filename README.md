# Agrotóxicos e Meio Ambiente - Site Educativo

## Sobre o Projeto

Este projeto é uma plataforma educativa dedicada a conscientizar sobre os impactos ambientais dos agrotóxicos e promover práticas agrícolas sustentáveis. Através de conteúdo informativo, dados estatísticos e soluções práticas, buscamos inspirar mudanças positivas no setor agrícola brasileiro.

## Missão

Nossa missão é educar agricultores, consumidores e comunidades sobre:
- Os impactos negativos do uso indiscriminado de agrotóxicos
- Alternativas sustentáveis e viáveis para a agricultura
- Práticas regenerativas que restauram a saúde do solo
- Tecnologias inovadoras que reduzem a dependência de químicos
- A importância da biodiversidade para sistemas agrícolas resilientes

## Características

### Design e Experiência
- **Design Responsivo**: Interface adaptável para desktop, tablet e dispositivos móveis
- **Tema Sustentável**: Paleta de cores inspirada na natureza (verdes, tons terrosos, azul água)
- **Animações Suaves**: Transições e efeitos visuais que melhoram a experiência do usuário
- **Navegação Intuitiva**: Menu fixo com scroll suave para todas as seções

### Conteúdo Educativo
- **Informações Baseadas em Dados**: Estatísticas reais sobre uso de agrotóxicos e seus impactos
- **Soluções Práticas**: Alternativas viáveis e comprovadas cientificamente
- **Recursos Visuais**: Imagens de alta qualidade que ilustram práticas sustentáveis
- **Linguagem Acessível**: Conteúdo técnico apresentado de forma clara e compreensível

### Funcionalidades Interativas
- **Scroll Animations**: Elementos aparecem gradualmente conforme o usuário navega
- **Cards Interativos**: Efeitos hover que destacam informações importantes
- **Menu Mobile**: Navegação otimizada para dispositivos móveis
- **Links de Seção**: Navegação rápida entre diferentes tópicos
